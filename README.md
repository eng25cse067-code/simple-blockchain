\# Simple Blockchain Using JavaScript



\## Project Overview

A beginner blockchain simulation developed using JavaScript and Node.js.



\## Features

\- Creates a genesis block

\- Adds transaction data

\- Generates SHA-256 hashes

\- Links blocks using previous hashes

\- Validates blockchain integrity

\- Detects modified transaction data



\## Technologies Used

\- JavaScript

\- Node.js

\- SHA-256

\- Git and GitHub



\## How to Run

1\. Install Node.js.

2\. Clone this repository.

3\. Open the project folder in PowerShell.

4\. Run: node blockchain.js



\## Testing

The blockchain should initially return true for validity.

After modifying transaction data, the validation should return false.



\## Limitation

This is an educational blockchain simulation, not a distributed blockchain network.
